# 每日得分

一个手机优先的纯前端打卡网页，可直接用 GitHub Pages 发布。

## 发布到 GitHub Pages

1. 新建一个 GitHub 仓库，将本目录所有文件上传到仓库根目录。
2. 打开仓库的 **Settings → Pages**，在 **Build and deployment** 选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/(root)`，保存。数分钟后 GitHub 会提供访问地址。

默认满分目标为 100 分：早起 8、学 AI 16、健身 12、网球 12、控食 10、外语学习 10、IP 18、Sidejob 14。每项均有三个完成等级。

数据保存在当前浏览器的 LocalStorage 中：适合个人手机使用；更换浏览器/设备时，历史数据不会自动同步。
